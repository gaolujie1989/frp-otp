优化 OTP 授权页面，改善手机操作体验。

- 放大验证码输入框和按钮，并适配窄屏布局。
- 新增“读取剪贴板”按钮：去除首尾空白后，仅接受 6 位数字，保留前导零，不自动提交。
- 剪贴板内容无效、权限被拒绝或浏览器不支持时给出提示，并保留原输入。
- 提交成功、验证码错误、限流或请求错误时，在表单上方显示结果，始终保留表单。

## 升级

配置与 v0.1.1 兼容，可继续使用现有密钥、授权时长和信任网段。替换程序或重建容器后生效；服务重启会清空临时授权。

剪贴板读取通常要求浏览器通过 HTTPS 或 localhost 访问。应用继续提供 HTTP，可由现有 WAF/反向代理提供 HTTPS；不支持读取时仍可手动输入或粘贴。

## 下载与 Docker

提供 Linux、Windows、macOS 的 amd64/arm64 压缩包及 SHA256SUMS。发布包内示例配置密钥为空。

Docker 镜像支持 Linux amd64/arm64：

```bash
docker pull ghcr.io/gaolujie1989/frp-otp:v0.1.2
```

Docker 发布成功后，`latest` 指向 v0.1.2。
