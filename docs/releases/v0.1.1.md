新增可配置授权时长和信任网段，默认授权从五分钟调整为四小时。

- `grant_duration`：默认 `4h`，支持 `30m`、`1h30m` 等正数时长。
- `trust_networks`：默认 `["10.0.0.0/8", "192.168.0.0/16"]`，命中网段的访客免验证码放通。
- 自定义信任网段列表会替换默认值，设置 `[]` 可关闭全部免验证放通；支持 IPv4/IPv6 CIDR。
- 启动时校验时长和网段，授权页面及成功提示显示实际配置时长。
- 同步更新示例配置、发布包配置模板及说明文档。

## 配置与升级

```json
{
  "BindAddress": "127.0.0.1:9000",
  "secret": "你的现有密钥",
  "grant_duration": "4h",
  "trust_networks": ["10.0.0.0/8", "192.168.0.0/16"]
}
```

旧配置可继续使用，省略新增字段时采用上述默认值。升级后默认会免验证放通这两个网段；如需所有访客继续验证，请显式配置 `"trust_networks": []`。修改配置后重启生效，重启会清空临时授权；已有连接不会在授权到期时主动断开。

信任网段匹配 frps 上报的访客 IP，独立于 X-Forwarded-For 可信代理解析和插件回调来源限制。

## 下载与 Docker

提供 Linux、Windows、macOS 的 amd64/arm64 压缩包及 SHA256SUMS。示例配置密钥为空，首次使用须先运行 `-e key` 并填写密钥。

Docker 镜像支持 Linux amd64/arm64：

```bash
docker pull ghcr.io/gaolujie1989/frp-otp:v0.1.1
```

`latest` 将随本次 Docker 发布更新至 v0.1.1。
