首个精简版发布：一个 OTP 密钥、一份全局 IP 授权表，默认拒绝未授权访客；验证后允许该 IP 在五分钟内建立新连接。

- 删除域名、渠道、绕过模式、永久黑白名单和通知配置。
- 私网或回环直连来源才信任 X-Forwarded-For，从右向左解析代理链；私网 IP 本身不自动放行。
- 支持 TCP、HTTPS、STCP、TCPMUX；拒绝注册无法按本方案实施访客 IP 准入的 HTTP、UDP、SUDP、XTCP。
- 修复验证码限流、过期清理、严格解析、启动失败和优雅退出。
- Go 1.27.3，frp v0.71.1，pquerna/otp v1.5.0。

## 下载与使用

按操作系统和 CPU 下载对应压缩包，解压后运行（Windows 文件名为 frp-otp.exe）：

```bash
./frp-otp -e key
# 将生成的 Secret 填入 frp.otp.json，在认证器中导入生成的 URI。
./frp-otp -e web -c ./frp.otp.json
```

配置只有 BindAddress、secret；示例密钥为空，必须先生成并填写。认证器参数为 SHA-512、6 位、30 秒。frps 配置见包内 examples/frps.toml，须同时订阅 NewProxy、NewUserConn。

旧版配置不兼容，请替换配置。授权存在内存中，重启后清空；授权到期不主动断开已有连接。Web 服务只提供 HTTP。SHA256SUMS 用于验证下载文件。
